#### Q-002: 商业模式确认

| 属性 | 内容 |
|------|------|
| 问题编号 | Q-002 |
| 问题描述 | 小说阅读网站的商业模式是什么？MVP阶段是否需要包含付费功能（VIP订阅、按章购买）？ |
| 提问对象 | 业务方 |
| 优先级 | 高 |
| 影响范围 | 用户系统、阅读器、产品定位 |
| 状态 | 待确认 |

**背景分析**：
- 免费模式：需广告系统支撑收入
- 付费模式：需支付系统、会员体系、内容定价
- 混合模式：免费+广告，VIP去广告+特权

**建议方案**：
- MVP阶段采用纯免费模式，聚焦用户体验
- V1.1或V1.2再引入付费功能
- 广告系统可在V1.1引入，位插在详情页和章节间

#### Q-003: 用户注册方式

| 属性 | 内容 |
|------|------|
| 问题编号 | Q-003 |
| 问题描述 | 用户注册是否支持第三方登录（微信/QQ/微博/手机号一键登录）？还是仅支持邮箱/手机号注册？ |
| 提问对象 | 业务方 / 技术负责人 |
| 优先级 | 中 |
| 影响范围 | 用户系统设计、开发工作量 |
| 状态 | 待确认 |

**背景分析**：
- 第三方登录（微信/QQ）可降低注册门槛，提升转化率
- 但需要申请第三方开发者资质，增加对接工作量
- 邮箱/手机号注册通用性强，开发成本低

**建议方案**：
- MVP阶段：邮箱+手机号注册（成本低，开发快）
- V1.1：增加微信/QQ第三方登录
