### US-003: 沉浸式阅读

**基本信息**
- 优先级：MoSCoW — **Must**
- 故事点：13
- 所属Epic：小说阅读体验
- RICE评分：15.0

**用户故事**
**作为** 读者
**我想要** 在舒适的阅读器中阅读小说，支持字号调整、主题切换和翻页
**以便于** 长时间阅读不疲劳，享受沉浸式阅读体验

**验收条件**
```gherkin
场景: 打开阅读器
  Given 用户在小说详情页
  When 点击"开始阅读"
  Then 跳转到阅读器页面
  And 加载第一章（或上次阅读位置）内容
  And 显示章节标题和正文

场景: 调整字号
  Given 用户在阅读器
  When 点击"放大字号"按钮
  Then 正文字体增大2px
  When 点击"缩小字号"按钮
  Then 正文字体减小2px

场景: 字号边界限制
  Given 用户在阅读器
  When 字号已为14px，继续点击缩小
  Then 字号保持14px不变
  When 字号已为32px，继续点击放大
  Then 字号保持32px不变

场景: 切换阅读主题
  Given 用户在阅读器
  When 打开阅读设置面板
  And 选择"夜间模式"
  Then 阅读背景切换为深色，文字切换为浅色
  When 选择"护眼模式"
  Then 阅读背景切换为暖黄色调

场景: 上下章翻页
  Given 用户正在阅读第5章
  When 点击"下一章"
  Then 加载第6章内容，页面滚动到顶部
  When 点击"上一章"
  Then 加载第4章内容

场景: 首尾章边界
  Given 用户正在阅读第1章
  When 页面加载完成
  Then "上一章"按钮禁用
  Given 用户正在阅读最后一章
  When 页面加载完成
  Then "下一章"按钮禁用

场景: 键盘快捷键翻页
  Given 用户在阅读器页面
  When 按下键盘左箭头键(←)
  Then 加载上一章内容
  When 按下键盘右箭头键(→)
  Then 加载下一章内容

场景: 阅读进度自动保存
  Given 用户阅读到第12章并离开
  When 用户再次打开该小说
  Then "开始阅读"跳转到第12章
```
