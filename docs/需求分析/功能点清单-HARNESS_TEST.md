## RICE评分详解

### 评分标准

| 维度 | 说明 | 评分范围 |
|------|------|---------|
| Reach（覆盖面） | 功能影响的用户比例 | 1-10（10=100%用户） |
| Impact（影响力） | 对用户核心体验的影响 | 1-5（5=关键影响） |
| Confidence（置信度） | 对评分的信心 | 20%-100%（100%=完全确定） |
| Effort（工作量） | 实现所需人月 | 1-10（10=10人月） |
