# M01-03 搜索 — 功能点清单

## 功能点

| 功能点编号 | 功能点名称 | 功能描述 | 优先级 | 复杂度 | 原型对应 |
|-----------|-----------|---------|--------|--------|---------|
| M01-03-001 | 搜索框 | 顶部固定搜索框，支持输入关键词 | Should | 低 | 全局 |
| M01-03-002 | 关键词搜索 | 匹配标题、作者名、标签 | Should | 中 | 搜索结果页 |
| M01-03-003 | 搜索排序 | 结果按相关度排序 | Should | 中 | 搜索结果页 |
| M01-03-004 | 空输入提示 | 未输入关键词时提示"请输入搜索关键词" | Should | 低 | 全局 |
| M01-03-005 | 无结果提示 | 无结果时提示"未找到相关小说，换个词试试" | Should | 低 | 搜索结果页 |

## 输入输出

**输入**：用户输入关键词。

**输出**：搜索结果列表或提示信息。

## 验收标准

- 支持标题/作者/标签模糊匹配。
- 空输入和无结果场景提示明确。
