# M06-01 响应式与安全 — 功能点清单

## 功能点

| 功能点编号 | 功能点名称 | 功能描述 | 优先级 | 复杂度 | 原型对应 |
|-----------|-----------|---------|--------|--------|---------|
| M06-01-001 | 响应式布局 | 适配 PC/平板/手机 | Must | 中 | 全局 |
| M06-01-002 | JWT 认证 | 支持 Token 认证和续期 | Must | 中 | 全局 |
| M06-01-003 | RBAC 权限 | 读者/作者/管理员权限控制 | Must | 中 | 全局 |
| M06-01-004 | 密码加密 | bcrypt 加密存储 | Must | 低 | 全局 |
| M06-01-005 | HTTPS | 敏感数据传输加密 | Must | 低 | 全局 |
| M06-01-006 | API 限流 | 防止爬虫和滥用 | Must | 中 | 全局 |
| M06-01-007 | XSS/SQL 防护 | 输入过滤和参数化查询 | Must | 中 | 全局 |

## 输入输出

**输入**：用户请求、用户角色、数据。

**输出**：安全的响应、适配的界面。

## 验收标准

- 多端界面正常展示。
- 未授权访问被拒绝。
- 敏感数据加密传输和存储。
