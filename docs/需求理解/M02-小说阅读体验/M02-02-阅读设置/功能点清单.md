# M02-02 阅读设置 — 功能点清单

## 功能点

| 功能点编号 | 功能点名称 | 功能描述 | 优先级 | 复杂度 | 原型对应 |
|-----------|-----------|---------|--------|--------|---------|
| M02-02-001 | 字号调整 | A+/A- 调整字号，范围 14-32px，步长 2px | Should | 低 | 阅读器设置面板 |
| M02-02-002 | 日间模式 | 浅米色背景、深色文字 | Should | 低 | 阅读器 |
| M02-02-003 | 夜间模式 | 深色背景、浅色文字 | Should | 低 | 阅读器 |
| M02-02-004 | 护眼模式 | 暖黄色背景、深棕色文字 | Should | 低 | 阅读器 |
| M02-02-005 | 设置持久化 | 字号和主题保存到本地存储 | Should | 低 | 阅读器 |

## 输入输出

**输入**：用户点击/选择。

**输出**：实时更新的阅读界面、本地存储的设置值。

## 验收标准

- 字号最小 14px，最大 32px。
- 三种主题一键切换。
- 刷新后自动应用上次设置。
