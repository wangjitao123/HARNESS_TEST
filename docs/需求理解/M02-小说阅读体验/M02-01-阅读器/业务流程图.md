# M02-01 阅读器 — 业务流程图

## 阅读器打开流程

```mermaid
flowchart TD
    A[用户点击"开始阅读"] --> B{是否有阅读进度?}
    B -->|是| C[读取章节ID和字符偏移]
    B -->|否| D[默认第一章]
    C --> E[加载章节内容]
    D --> E
    E --> F[渲染阅读器]
    F --> G{用户操作}
    G -->|翻页| H[加载下一章/上一章]
    G -->|调整设置| I[保存设置到本地存储]
    G -->|添加书签| J[保存书签到数据库]
    G -->|离开| K[自动保存阅读进度]
```
