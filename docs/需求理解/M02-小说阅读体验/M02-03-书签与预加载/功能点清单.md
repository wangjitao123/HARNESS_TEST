# M02-03 书签与预加载 — 功能点清单

## 功能点

| 功能点编号 | 功能点名称 | 功能描述 | 优先级 | 复杂度 | 原型对应 |
|-----------|-----------|---------|--------|--------|---------|
| M02-03-001 | 添加书签 | 在阅读位置添加书签标记 | Should | 低 | 阅读器 |
| M02-03-002 | 书签列表 | 在用户中心查看书签并跳转 | Should | 低 | 用户中心 |
| M02-03-003 | 删除书签 | 删除已添加的书签 | Should | 低 | 用户中心 |
| M02-03-004 | 下一章预加载 | 提前加载下一章内容 | Should | 中 | 阅读器 |
| M02-03-005 | 预加载策略 | 仅预加载下一章，避免过度请求 | Should | 中 | 阅读器 |

## 输入输出

**输入**：用户操作、当前阅读位置。

**输出**：书签记录、预加载的章节内容。

## 验收标准

- 书签可增删查。
- 预加载减少翻章等待。
