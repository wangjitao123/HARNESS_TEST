# M04 用户管理

## 模块目标

管理用户账号、书架、阅读历史，为用户提供个性化阅读服务。

## 子模块

| 子模块编号 | 子模块名称 | 说明 |
|-----------|-----------|------|
| M04-01 | 注册/登录 | 账号注册、登录、安全策略 |
| M04-02 | 书架管理 | 收藏、阅读进度、阅读历史 |

## 涉及功能点

- F-005 书架管理
- F-006 用户注册/登录
- F-012 阅读历史（合并为书架子模块）

## 关键业务指标

| 指标 | 目标 |
|------|------|
| 注册转化率 | ≥ 30% |
| 人均书架收藏数 | ≥ 5 本 |
