# 产品代理模式 - 查看当前状态

## 功能描述

产品经理专用命令。一条命令查看项目全局状态：文档完成情况、Git变更状态、待评审文件、当前所处阶段、下一步操作建议。产品无需手动执行git status等命令。

## 输入参数

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| docs_dir | string | 否 | 文档目录（默认读取_project.json） | docs |

## 使用示例

### 示例1：查看当前状态

```bash
/pm-status
```

## AI自动执行的操作

### 1. 读取项目配置
```
操作：读取 {docs_dir}/_project.json
获取：project_name, current_stage, pm_name, 分支名
```

### 2. 检查Git状态
```
操作：git status --porcelain
操作：git log --oneline -5
获取：未提交变更、最近5条提交记录
```

### 3. 检查文档完成情况
```
扫描 {docs_dir}/ 目录：
  - 需求分析/ → PRD是否存在？用户故事是否存在？待确认问题是否存在？
  - 需求开发/ → 功能点清单是否存在？BRD是否存在？
  - 需求理解/ → 原型设计是否存在？业务流程图是否存在？
  - 系统设计/ → 系统设计文档是否存在？
  - 概要设计/ → 架构设计是否存在？数据库设计是否存在？
  - 详细设计/ → 排期计划是否存在？
```

## 注意事项

1. **只读操作**：pm-status只读取状态，不修改任何文件
2. **自动推断当前阶段**：根据已完成的文档推断项目处于哪个阶段
3. **显示下一步建议**：根据当前状态推荐下一步操作
4. **显示Git变更**：让产品知道哪些文件改了还没保存
